# Gayan Ganga Coaching Center - Native Android

Clean native Android project using Kotlin, Jetpack Compose and Firebase.

Package: `com.gayangangacoachingcenter.app`

Build outputs:
- Release APK: `app/build/outputs/apk/release/app-release.apk`
- Release AAB: `app/build/outputs/bundle/release/app-release.aab`

GitHub Actions workflow builds both artifacts automatically.

Important: this is a native Android app, not a WebView app.
